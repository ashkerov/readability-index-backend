# Веб-сервис: Расчет индекса читабельности текста

Бэкенд-часть веб-приложения для работы с текстами разных жанров и автоматического расчета их индекса удобочитаемости (на основе средней длины предложений и доли уникальных/сложных слов). Разработано в рамках курса РИП.

## Структура Базы Данных

Проект включает 4 основные таблицы, спроектированные по правилам 3НФ:

* **users (Пользователи)**
  * `id` (Integer, Primary Key)
  * `username` (String) — логин
  * `first_name` (String) — имя
  * `last_name` (String) — фамилия

* **publications (Услуги / Тексты)**
  * `id` (Integer, Primary Key)
  * `title` (String) — название текста
  * `description` (String) — краткое описание
  * `status` (String) — статус (опубликован, удален)
  * `genre` (String) — жанр текста (поле по теме)
  * `avg_length` (Integer) — среднее количество слов в предложении (поле по теме)
  * `unique_words_share` (String) — доля уникальных/сложных слов (поле по теме)
  * `image_url` (String) — ссылка на обложку в MinIO
  * `video_url` (String) — ссылка на видео/аудио превью в MinIO
  * `creator_id` (Integer, Foreign Key) — автор текста

* **requests (Заявки)**
  * `id` (Integer, Primary Key)
  * `status` (String) — статус (черновик, сформирована, завершена, удален)
  * `created_at` (Datetime) — дата создания черновика
  * `formed_at` (Datetime) — дата формирования заявки
  * `completed_at` (Datetime) — дата обработки модератором
  * `creator_id` (Integer, Foreign Key) — создатель заявки
  * `moderator_id` (Integer, Foreign Key) — модератор, завершивший заявку

* **request_items (Связь М-М / Корзина)**
  * `id` (Integer, Primary Key)
  * `request_id` (Integer, Foreign Key) — ссылка на заявку
  * `publication_id` (Integer, Foreign Key) — ссылка на текст
  * `readability_index` (Float) — расчетный индекс читабельности текста (вычисляется автоматически при формировании)

## HTTP Методы веб-сервиса (REST API)

| HTTP-метод | Маршрут | Описание |
| :--- | :--- | :--- |
| **GET** | `/api/publications` | Получение каталога текстов с фильтрацией (по длине и жанру) |
| **GET** | `/api/publications/{id}` | Получение подробной информации об одном тексте |
| **POST** | `/api/publications` | Добавление нового текста (с загрузкой медиа в MinIO) |
| **POST** | `/api/requests/items` | Добавление текста в текущую заявку-черновик (корзину) |
| **PUT** | `/api/requests/items/{id}` | Ручная корректировка атрибутов связи м-м |
| **DELETE** | `/api/requests/items/{id}` | Удаление конкретного текста из заявки-черновика |
| **GET** | `/api/requests/cart-icon` | Получение метаданных для иконки корзины (ID и количество) |
| **GET** | `/api/requests` | Получение списка заявок с фильтрацией по статусу |
| **GET** | `/api/requests/{id}` | Детальный просмотр заявки и вложенных текстов |
| **PUT** | `/api/requests/{id}` | Редактирование базовых полей заявки |
| **PUT** | `/api/requests/{id}/form` | Формирование заявки (срабатывает автоматический расчет индекса читабельности для текстов) |
| **PUT** | `/api/requests/{id}/complete` | Завершение заявки модератором |
| **DELETE** | `/api/requests/{id}` | Логическое удаление заявки (смена статуса) |
| **POST** | `/api/users/register` | Регистрация нового пользователя |
| **POST** | `/api/users/login` | Аутентификация пользователя (заглушка) |
| **POST** | `/api/users/logout` | Деавторизация пользователя (заглушка) |
